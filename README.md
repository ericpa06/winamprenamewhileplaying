# Winamp Rename While Playing

A Winamp General Purpose plugin intended to add `FILE_SHARE_DELETE` to local-file read opens inside Winamp, allowing compatible editors and Explorer to rename or atomically replace a playing track without rebuilding Winamp.

The x86 Windows build is produced by GitHub Actions. See the workflow under `.github/workflows/build-release.yml`.

**Status:** source candidate; Windows build and live Winamp/WACUP integration must be verified by CI and on the target player before treating this as production-ready.
